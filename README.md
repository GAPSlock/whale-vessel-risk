# Predictive Whale–Vessel Collision Risk & Adaptive Routing System

This repository contains the scientific implementation of a predictive risk system for North Atlantic Right Whale (NARW) and vessel collisions. The system uses a continuous-time Neural Partial Differential Equation (PDE) formulation, specifically solved via a Tensorized Fourier Neural Operator (TFNO), to model latent whale density fields based on spatiotemporal observations and environmental advection fields.

## System Architecture

The project is structured around a multi-phase data and modeling pipeline.

### 1. Data Pipeline (Observation & Environment)
*   **Biological Target (`presence_intensity`)**: Formulated as a temporally blocked, effort-adjusted Kernel Density Estimate (KDE) continuous field. Modality-specific efforts (acoustic distance-decay and visual line-transect) are explicitly separated before fusion.
*   **Environmental Priors**: Incorporates high-resolution oceanographic variables (e.g., CMEMS GLORYS daily-mean ocean physics, linearly interpolated to 6-hour temporal bins) including current velocities (u, v), temperature, and bathymetry.
*   **Grid Specs**: Operates on a regular 0.05° spatial grid over the Cape Cod Bay / Gulf of Maine region (approx. 41.0–43.5°N, -71.5–-68.5°W).

### 2. Modeling Framework (Latent-Field PDE / TFNO)
*   **Dynamics**: Models the whale density as a continuous spatiotemporal latent field obeying a forced advection-diffusion PDE. 
*   **Solver**: Utilizes a Tensorized Fourier Neural Operator (TFNO) via `neuraloperator` to efficiently map a 24-hour historical state block into a 72-hour forecast horizon in the spectral domain.
*   **Optimization**: Fully FP16 Autocast (without PyTorch GradScaler due to `ComplexFloat` FFT operations) targeting memory efficiency for edge-capable GPU inference.

### 3. Routing Optimization (Future Phase)
*   An A* / dynamic programming graph router that ingests the 72-hour forecast tensor (Cost = Time + $\lambda$ * Risk) to optimize vessel paths continuously, minimizing strike probability while bounding transit delay.

## Setup & Environment

**Requirements:**
* Python 3.12+
* PyTorch 2.5.1+ (cu124)
* neuraloperator, torch-geometric
* scipy, pandas, xarray

**Local Installation:**
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt  # (Once generated)
```

## Current Status
*   **Phase 0 (Foundation)**: Accepted. Environment, hardware memory benchmarks, and AMP stability testing completed.
*   **Phase 1 (Data Pipeline)**: In Progress. Initial raw-data physical audits (OBIS-SEAMAP, NOAA ArcGIS) are complete. Quantitative observation sparsity and PDE viability analysis indicates severe structural limitations for a continuous 6-hour latent-field formulation using strictly visual line-transect data.

## Note on Synthetic Data
Any software integration fixtures generated by the system are strictly tagged with the `SYNTHETIC_SOFTWARE_FIXTURE` flag. The training pipeline is designed to fail-closed if these files are passed, ensuring they never leak into the scientific evaluation.
